## 🔭 Featured Projects

The two security repositories are write-ups from labs I did during my exchange at ÉTS Montréal (winter 2026). Most were done in a team of four; the write-ups here are my own reformulation, in English and French.

1. **[software-security-labs](https://github.com/IlyasEHI/software-security-labs)**: low-level and web exploitation. Buffer overflows on Linux and Windows (ret2win, ret2shellcode with an ASLR bypass, a heap overflow), plus web attacks like LFI to RCE, SQL injection, XSS, file-upload bypasses, and command injection.
2. **[ets-security-labs](https://github.com/IlyasEHI/ets-security-labs)**: a wider range. Malware analysis, WebGoat web exploitation, a Linux host pentest up to root in a lab VM, applied cryptography and PKI, and a secure-authentication app built with Spring Security.
3. **[Keg-ineo-nutrition-app](https://github.com/IlyasEHI/Keg-ineo-nutrition-app)**: a Flutter app I built on a Junior Enterprise client mission, controlling BLE-connected ESP32 kitchen scales.

Where a lab is an attack, the write-up ends with how a developer would have closed the hole. The malware analysis focuses on detection instead, and the secure-authentication one is a defensive build rather than an exploit.
